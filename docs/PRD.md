# PRD — 잔상 항로 / Afterimage Route

## 1. 아이디어 후보 비교
| 후보 | 유형 | 장점 | 7일 위험 |
|---|---|---|---|
| **잔상 항로** — 잠깐 본 항로를 기억으로 다시 그리는 퍼즐 | 웹 퍼즐 게임 | 1분 체험, 서버 불필요, 엔진을 순수 함수로 테스트 가능, 시드 공유로 재현 | 난이도 조절·재미 검증 필요 |
| 한 단어 시 카드 생성기 — 단어 하나로 타이포 포스터 생성 | 창작 도구 | 시각적 매력 | 품질이 폰트·디자인 취향에 좌우, 외부 폰트 없이 차별화 어려움 |
| 로컬 집중 타이머+작업 로그 | 실용 유틸리티 | 실용적 | 흔한 범주, 독창성 낮음, 저장소(DB) 설계 부담 |

**선택 이유:** 7일 안에 실제로 작동하고 다른 사람이 링크 하나로 즉시 체험 가능하며, 핵심 로직을 결정적으로 테스트할 수 있어 검증 근거가 명확함.

## 2. 목표 / 비목표
- 목표: 1분 안에 끝나는 공간 기억 루프, 모바일 360px·키보드·스크린리더 사용 가능, 오프라인 친화(서버 없음), 시드 재현.
- 비목표: 계정, 리더보드, 광고, 분석, AI/API, 결제, 효과 주장.

## 3. 주요 기능
미리보기 → 숨기기 → 칸 단위 복원(터치/키보드) → 실수 집계 → 다시 보기(연습 처리) → 결과(칸·시간·실수) → 같은 항로/새 항로.

## 4. UX 흐름
preview →(숨기기) recall →(완주) done; recall →(다시 보기) preview(revealed=true). 잘못된 칸은 진동 피드백+상태 문구(aria-live).

## 5. 기술 스택·아키텍처
네이티브 ESM HTML/CSS/JS, 빌드·의존성 없음. `engine.mjs`(순수 상태) → `view()`(기억 단계에서 route=null) → `app.js` 렌더러. 정답 정보는 기억 단계 DOM/ARIA/클래스/data 속성에 들어가지 않음. Node 내장 정적 서버와 node:test.

캐시 대응: `public/` 자산 URL에 내용 기반 버전(`?v=sha256 앞 12자`)을 붙이고 `npm run check`가 불일치를 막음.

## 6. ERD / DBML
**적용하지 않음.** 데이터베이스가 없습니다. 모든 상태는 한 판 동안 브라우저 메모리에만 존재하고, 지속 저장되는 관계형 데이터가 없습니다. (추후 localStorage 기록을 넣더라도 단일 키-값이라 ERD가 필요하지 않음.)

## 7. 위험
재미/난이도 미검증 · 실제 브라우저 접근성 미검증 · 공개 호스팅 경로 미정(인증·유료 없이 가능한 방법 필요).
