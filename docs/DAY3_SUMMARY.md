1. **run1 오프라인 안내 발견성:** 오프라인 설명이 접힌 `<details>` 안에만 있어 찾기 어려웠다 → 푸터에 항상 보이는 문구로 옮김(`aa9755b`).
2. **run3 어제 항로 「오늘 최고」 문구:** `daily-2026-11-09` 화면에 「오늘 최고 실수 0 · 30.2초」가 나옴. 저장 규칙은 시드별이라 유지하고 표시만 `bestTitle`(오늘/어제/날짜 최고)로 수정(`81ca35e`).
